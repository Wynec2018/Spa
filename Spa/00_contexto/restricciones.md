# Supuestos y restricciones
- Se asume que tanto las trabajadoras como los clientes disponen de un dispositivo móvil básico o acceso a internet para visualizar estados o recibir confirmaciones.

- El spa cuenta con una conexión a internet estable que permite la actualización en tiempo real de los estados de las trabajadoras y las camas.

# Restricciones técnicas

- El sistema debe ser responsivo (compatible con smartphones y tablets) para facilitar el uso rápido por parte de la secretaria y las trabajadoras.

- Integración con una pasarela o visualizador de pagos por código QR estático o dinámico.

# Restricciones organizacionales

- El personal (trabajadoras y secretaria) requerirá una breve capacitación de 30 minutos para familiarizarse con la interfaz amigable del sistema.

- Solo la dueña (superusuario) tendrá privilegios para registrar nuevas trabajadoras, modificar servicios o revisar reportes financieros globales.

# Decisiones pendientes
