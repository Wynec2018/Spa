# Criterios de aceptación
- CA-001: El sistema debe reflejar de forma inmediata (en menos de 3 segundos) el cambio de estado de una trabajadora de "Libre" a "Ocupada" una vez que la secretaría o el sistema asigne un servicio.
- CA-002: Si un cliente intenta reservar cuando las 6 camas o las 10 trabajadoras se encuentran ocupadas, la interfaz debe bloquear el horario seleccionado y sugerir de manera amigable el siguiente espacio disponible.
- CA-003: La secretaría debe contar con un botón de "Verificar Pago QR" que le permita aprobar o rechazar comprobantes con un solo clic, actualizando el estado de la reserva de "Pendiente" a "Pagada/Confirmada".
- CA-004: La secretaría o la trabajadora pueden asignar el tiempo del servicio.
